# MainAPP 易用性建议

> 基于源码实地走查（`MainWindow` / `Home` / `ProductionLine` / `DeviceManager` / `Settings` / 弹窗 / 主题）整理的易用性评估。
> 看板定位：工厂车间实时大屏 + 设备配置后台。两类用户差异极大——**大屏前的巡检员（远距、只读、偶尔交互）** 与 **站在工位前的配置员（近距、高频输入）**，建议分开优化。

---

## 一、已经做得好的（保留）

- **深色主题对比度有意识调优**：`ThirdlyTextBrush` 从 `#6B7280` 提亮到 `#8B92A0`，在 `#1A2029` 上约 4.6:1，满足 WCAG AA（Brushes.xaml:23-25）。
- **导航栏 UIA 可达**：侧边栏用原生 `ListBox` + `AutomationProperties.Name` 绑定，便于自动化测试（MainWindow.xaml:209-222）。
- **报警做了色盲友好双编码**：色条 + 文字徽章（HomeRealtimeAlarmsCard.xaml:200-206）。
- **空状态、搜索、筛选、输入校验（端口/间隔范围）齐备**（SettingsView.xaml:249-307）。
- **危险操作有二次确认**：删除设备、导入覆盖、OEE 清零都弹 `MessageBox` 警示（DeviceManagerViewModel.cs:286-289, 640）。
- **PLC 断线横幅 + 右上角 Growl + 侧栏状态点**，连接异常有感知。

## 二、P0 — 核心工作流断裂 / 高影响

### 1. 主页（0）与概览（4）职责重叠
`MainWindowViewModel.PageNames` 中「主页=生产仪表板」「概览=最近24小时生产概览」内容高度同质，操作员不知道该开哪个。
**建议**：明确分工或合并——
- 主页 = **实时运营驾驶舱**（当前发生什么，盯屏用）；
- 概览 = **近 24h 回顾与分析**（趋势、对比、班次日报，复盘用）；
- 两页标题、布局、强调维度明显区分，避免「又一个仪表盘」的既视感。
> **【已进一步缓解 2026-08-01】**：概览页已改名为「生产复盘」，主页中间卡片已改为「当前生产状态」，与「生产仪表板」形成“当前状态 / 历史复盘”的命名分工；两页指标内容仍可在后续版本继续减少重复。

### 2. 缺少统一报警中心 / 安灯闭环（P0 缺口）
报警被拆成两处：主页实时故障卡（运行态活跃报警）+ 设备管理「报警管理」Tab（报警**配置**）。两者无统一入口，且：
- **没有「确认 / Ack」**：Home 只有「静音」（仅抑制闪烁），操作员无法把报警标记为「已看到 / 处理中 / 已解决」；
- **没有报警历史与归档**：活跃报警清除后即不可见；
- **无声音提示**：嘈杂车间仅靠视觉闪烁不够。
**建议**：新增「报警中心」页（已在缺口清单 P0），提供 活跃 / 已确认 / 历史 三态、Ack 按钮、处理备注、声音告警（可静音）、按设备/级别/时间检索。

### 3. 新报警闪烁被移除（功能回归）
`HomeRealtimeAlarmsCard.xaml:155` 注释写明：「闪烁动画因 Binding 异步解析导致路径不可用，已移除」。目前新报警仅靠静态底色变化，**远距大屏上抓不住注意力**。
**建议**：用不影响 Binding 的方案重做高亮（如外层 `Border` 上的 `ColorAnimation`/`OpacityAnimation`，或在 ViewModel 计时后切换一个独立的 `IsFlashing` 属性驱动 `DataTrigger`），保留静音开关但默认开启闪烁。
> **【已修复 2026-08-01】**：主页新报警改为独立外层边框低频脉冲，保留静音开关，不再让整张报警卡片变色或闪烁。

### 4. 大屏远距可读性不足
- 最小字号 10–13px（KPI 标签、图例、`KANBAN SYSTEM`、副文本）在 3–5 米外不可读；
- 根 `Viewbox` 用 `Stretch="UniformToFill"`（MainWindow.xaml:20），非 16:9 屏幕（超宽、4:3 工位屏）会**裁切边缘内容**。
**建议**：
- 增加「大屏模式」：放大基础字号、降低卡片密度、关键数字用 ≥28px 等宽字体；
- 非 16:9 屏改用 `Uniform`（信箱化留边）或按实际分辨率自适应，避免裁切。

## 三、P1 — 重要体验缺陷

### 5. 侧边栏默认折叠丢上下文 + 无快捷键提示
> **【已部分修复 2026-08-01】**：侧边栏默认改为展开，配置员首次进入即可看到页面名称；折叠后的 Tooltip、快捷键提示和轮播模式待后续补齐。

### 6. 报警处理闭环缺失（承接 P0-2）
Home 实时故障卡仅有「静音」。无 Ack、无处理人、无历史。
**建议**：在卡内/报警中心加「确认」按钮，状态机 `活跃 → 已确认 → 已解决`，并保留时间戳与操作人。

### 7. 设备列表拖拽排序体验脆弱
`DeviceManagerView.xaml:104-114` 用 `AllowDrop` + 自定义 `OnListDrop`，**无插入指示线、无撤销、触屏难用**，20+ 设备排序极不友好。
**建议**：增加「上移 / 下移 / 置顶」按钮；若保留拖拽，至少绘制插入位置指示线并支持 `Ctrl+Z` 撤销。

### 8. 「更多」菜单藏危险操作
复制 / 导入 / 导出 / 恢复上一版本 / 生成虚拟设备 都收进「更多」右键菜单，展开前无文字提示；其中「恢复上一版本」会**覆盖当前配置**，仅 tooltip 警告（DeviceManagerView.xaml:222-230）。
**建议**：「恢复上一版本」改为二次确认弹窗并列出将被覆盖的内容；低频但重要的「导出 / 导入」可提升为常驻按钮。
> **【已修复 2026-07-27】**：「恢复上一版本」已加密码弹窗确认（`DeviceManagerViewModel.RollbackToBackup()` 调用 `_dialog.ShowPasswordInput` 校验固定密码，与「生成虚拟设备」一致）；原 YesNo 弱确认移除，tooltip 改为「（需密码确认）」。

### 9. 密码对话框不自动聚焦 + 固定背门密码
`PasswordInputDialog.xaml.cs` 仅 `PasswordBox.KeyDown` 处理 Enter，**打开时不自动聚焦输入框**；且逻辑为固定密码 `123456`（见授权模块问题清单 #5），既不安全也无提示。
**建议**：`Loaded`/`Activated` 时 `PasswordBox.Focus()`；背门密码改为可配置或移除，并在对话框说明用途。
> **【已修复 2026-07-27】**：`PasswordInputDialog.xaml` 根 Window 加 `FocusManager.FocusedElement="{Binding ElementName=PasswordBox}"`，弹窗打开即聚焦密码框（对所有调用方生效）。背门密码 `123456` 仍保留（与生成虚拟设备共用，但属授权模块问题清单 #5，待统一改造）。

### 10. 无首次运行引导与帮助入口
设备/PLC 地址/报警阈值配置复杂，但缺少引导；「生成虚拟设备」需密码、路径深。
**建议**：首次启动激活向导 + 顶部「?」帮助入口（跳文档/快捷说明）+ 各复杂表单的 inline 帮助文字。

### 11. 保存范式不统一
设备页用独立「保存」+「未保存」星标（Ctrl+S 提示），设置页用「保存设置」按钮，但**无 Ctrl+S 提示**。两处范式不一致，易漏保存。
**建议**：统一为「草稿自动暂存 + 显式提交」或全局 `Ctrl+S` 通用快捷键，并在保存成功后给出一致的成功反馈（Toast 文案/位置统一）。

## 五、落地优先级建议

1. **先补闭环**：P0-2/P0-3（报警中心 + 闪烁回归）—— 这是看板的核心价值，当前最薄弱环节。
2. **再做大屏**：P0-4 + P1-5（可读性 + 轮播 + 快捷键）—— 决定大屏是否「看得清、用得动」。
3. **理顺信息架构**：P0-1（主页/概览分流）—— 低成本高收益。
4. **收尾打磨**：P1-7~11、P2 各项按版本迭代。

> 附：与现有缺口清单一致——报警中心/安灯、工单排产、大屏轮播为 P0；报表中心、质量追溯、设备健康预测、操作员锁屏为 P1。
