工单管理 · 5 套改进预览

点击下方卡片在新标签页打开对应 HTML 静态稿。均为暗色主题，用于评审信息架构与布局方向，非最终实现。

推荐

V1 · 均衡混合版

页头全局 KPI + 左表格式列表（含进度列）+ 右详情看板 + 底部 sticky 操作。兼顾排程与执行。
适合：计划员 + 产线主管共用 · 在现有 WPF 双栏基础上渐进改造
 执行优先

V2 · 执行看板版

全宽表格列表，选中后右侧紧凑 KPI + 进度条，操作按钮紧贴工单头。信息密度最高。
适合：日常盯进度、快速开工/完工 · 工单量大、少看 SN/甘特
 数据中心

V3 · 指挥台版

顶栏筛选 + 全宽数据表，详情以右侧滑出抽屉呈现。列表始终占主视野。
适合：多工单并行浏览 · 频繁切换对比 · 大屏显示器
 轻量

V4 · 紧凑卡片版

左窄卡片列表，右宽详情流式卡片。筛选折叠为单行，减少首屏控件。
适合：笔记本小屏 · 强调单工单深读 · 当前实现的轻量变体
 深度追溯

V5 · 分 Tab 详情版

左列表不变，右侧详情分 Tab：概览 / SN 追溯 / 排程甘特 / 时间线。避免单页过长滚动。
适合：质量追溯、排程分析场景 · SN/甘特使用频率高
