# 多语言资源维护

## 唯一源文件

所有界面和 Core 共享提示的翻译维护在 `MainAPP/Resources/Localization.csv`。

CSV 使用 UTF-8 with BOM，前两列固定，后续列是文化代码。当前表头为：

```text
Resource,Key,zh-CN,en-US,ja-JP,pt-BR
```

`Resource` 只能是 `Wpf` 或 `Core`。Wpf 行生成 `Strings*.resx` 和 `Strings.cs`，Core 行生成 `Messages*.resx`。
新增语言时只需在表头增加合法的 .NET 文化代码并填写每行翻译；生成器会同步生成 WPF、Collector.Core 和 Web 的语言目录及卫星资源。删除语言列时，生成器会在普通生成模式清理对应的旧卫星资源。

## 构建与校验

构建 `MainAPP`、`Kanban.Collector.Core` 或 `Kanban.Web` 时会自动运行生成器。手动校验全部生成文件：

```powershell
python ci/generate_localization.py --check
```

需要重新生成全部文件时运行：

```powershell
python ci/generate_localization.py
```

查看各资源范围的非空率和疑似英文兜底比例：

```powershell
python ci/generate_localization.py --coverage-report
```

`ci/quality-gates.ps1` 会在构建前显式执行 `--check`，并默认阻止 WPF 非中文语言的疑似英文兜底比例超过 94% 或数量超过当前基线（葡萄牙文当前为 1959 条）。这是防止继续恶化的过渡门槛，不代表英文相同的技术术语已经完成人工翻译；当前葡萄牙文长尾仍需逐步补齐。

旧命令 `generate_wpf_strings.py` 和 `generate_web_loc.py` 仍保留为兼容入口。

## 工业现场修改已有翻译

发布包中可放置一份可选覆盖文件：

```text
%APPDATA%\Kanban\Config\Localization.override.csv
```

也可以在启动程序前设置 `KANBAN_DATA_DIR`，覆盖文件位于该目录下的 `Config` 子目录。Local 模式由 MainAPP 读取本机文件；Remote 模式以 Collector 所在主机的文件为权威，MainAPP 本机文件只作为 Collector 尚未连接时的降级来源，Web 屏端始终读取 Collector 下发的覆盖快照。
可复制 `MainAPP/Resources/Localization.override.sample.csv` 作为模板。覆盖文件仍使用相同的动态表头：

```text
Resource,Key,zh-CN,en-US,ja-JP,pt-BR
```

示例：只修改英文的主页标题，其他语言列留空：

```csv
Resource,Key,zh-CN,en-US,ja-JP,pt-BR
Wpf,Nav_Home,,Production Dashboard,,
```

启动时 MainAPP 和 Collector 会读取该文件。支持 UTF-8（含/不含 BOM）、UTF-16 BOM，以及 Windows 当前代码页导出的无 BOM 文件；逗号、分号和 Tab 分隔符会自动识别。MainAPP 与 Collector 都严格校验 Wpf/Core Key、语言列、复合格式占位符；Collector 应用 Core 行，并向 Remote Web 屏端提供 Wpf 行。文件不存在时使用内置翻译，文件校验失败时整份覆盖不生效并回退内置翻译。

修改覆盖文件后需要重启 MainAPP；Remote 部署应修改并重启 Collector 主机上的覆盖文件，再重启/刷新屏端，使浏览器屏端重新读取覆盖内容。无需安装 .NET SDK、Python 或重新编译。

## 翻译约束

- 每个资源键在 CSV 的所有语言列中都必须有非空值。
- `{0}`、`{1:F0}` 等格式占位符在所有语言列中必须保持一致，并通过复合格式语法校验。
- 覆盖文件只允许修改已存在的 `Resource + Key`，不能新增资源键或语言。
- 覆盖文件可以只填写要修改的语言列；空列表示继续使用内置翻译。
- 默认语言是 `zh-CN`。旧版 `AppLanguage`/整数 Hub 字段仅用于兼容，运行时语言以 CSV 文化代码为准。
- 当前葡萄牙语语言代码为 `pt-BR`；新增语言不需要增加 `AppLanguage` 枚举值。
- 当前未人工翻译的长尾葡萄牙文条目以英文作为临时兜底；新增正式翻译直接修改 CSV 的 `pt-BR` 列。
- 不要直接编辑生成的 `.resx`、`Strings.cs` 或 Web `Localization.cs`，下次构建会覆盖这些文件。
