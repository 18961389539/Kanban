# 真机冒烟验证清单（审查修复 2026-08-13 批）

> 背景：本批修复涉及运行时行为（班次锁、Remote 链路超时/截断/批量、恢复重放退避、订阅单飞、
> StringFormat 显示、数据口径）。单测全绿不等于真机行为正确，需按本清单验证。
> 前提：本机 `KanbanCollector`/`KanbanPlcSimulator` 两个 Windows 服务占用 5129/4999 且锁住 bin 产物，
> 冒烟前需**管理员权限**停止服务，否则新二进制无法部署。

## 一、环境准备

```powershell
# 1. 停演示服务（需管理员）
Stop-Service KanbanCollector,KanbanPlcSimulator -Force

# 2. 构建 + 发布新二进制
dotnet build Kanban.slnx -c Release
.\ci\publish-all.ps1 -OutputDir .\publish   # 或按需带 -SkipWeb -SkipSim

# 3. 重启环境（start_env.ps1 或手动）
.\start_env.ps1
```

## 二、验证清单（按优先级）

| # | 验证点 | 方法 | 预期 |
|---|---|---|---|
| 1 | **StringFormat 修复** | 打开 MainAPP 主页：OEE/良品率/产量 KPI、设备详情 OEE 三环、审计页时间列 | 显示真实数字（如 "95.1%"、"1,234"、"10:30"），而非字面量 "P1"/"N0"/"HH:mm" |
| 2 | 断线横幅 | 断开 PLC 连接 → 主页出现断线横幅；重连 → 横幅消失 | 可见性正确切换 |
| 3 | 上班次对比 | 演示环境重启后观察"上班次对比"区 | 无数据时不再每 3s 打历史库（日志/CPU），60s 退避重试 |
| 4 | 班次编辑保存 | 设置页改班次保存（Local 模式） | 产线页班次条实时刷新（Shifts 原地更新修复）；保存期间无异常 |
| 5 | 报警统计 | 报警中心 Top 排行 | 排行按**触发次数**降序，右侧徽标显示次数（不再显示时长） |

| 8 | 近 7 天峰值 | 概览页切"近 7 天" | 峰值/谷值标签显示日期（MM-dd），不再恒 00:00 |

## 四、异常排查提示

- 冒烟 FAIL 但页面正常 → 先查 ci/wasm-smoke.js 的选择器/候选词是否漂移（优先于怀疑服务端）。
- Remote 模式工单不刷新 → 查 Collector 日志"事件连接"相关行；本批前该路径从未真正建立过订阅。
