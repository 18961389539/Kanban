配方管理页（RecipeManagerView）UI 改进

现状：顶部下发栏 + 左侧纯文本配方 ListBox + 右侧内联编辑（ItemsControl 逐行 TextBox），无搜索/校验/对比/历史。以下 5 个方案为独立预览，可组合落地。
1

配方库卡片化 + 搜索 / 机型筛选

易实现收益高

问题：左侧是只有"名称+机型"两行文字的 ListBox，配方多了以后只能靠肉眼滚动找；无搜索、无筛选、无配方详情摘要。

方案：改为卡片流（列表/卡片切换），卡片展示 配方名·机型·参数数·更新时间；顶部加搜索框（按名称/参数名模糊匹配）与机型筛选胶囊（通用 / 注塑机1 / 注塑机2 / 组装机1）；选中卡片即进入右侧编辑。

2

参数表升级 DataGrid：虚拟化 + 行内校验 + 列宽可调

中等收益高

问题：ItemsControl 渲染全部行（几百参数即卡顿），无行号、无单元格校验（类型/范围/地址格式错到下发才报），列宽不可调，Bool 下拉与数值框切换靠 DataTrigger。

方案：换 DataGrid：行虚拟化 + 表头冻结 + 列宽拖拽 + 行号列；单元格级实时校验（PLC 地址正则、Min≤Value≤Max、类型可解析），非法单元格红框 + 提示；底部"添加行"直接新增；按住行头可拖拽排序。

3

下发三步向导：目标 → 差异预览 → 进度与逐项结果

中等收益高

问题：下发是"一键梭哈"：点下发立刻写入，无确认；机型不匹配不拦截；逐项结果藏在 90px 的小滚动条里，无进度感；Remote 模式失败了只能看红字干瞪眼。

方案：顶部改为三步进度条：① 选设备（机型不匹配黄色警告，可强制）→ ② 差异预览（对比 PLC 当前值，绿色=将写入，仅展示变化项）→ ③ 执行（总进度条 + 逐项实时状态，失败项红色 + 失败原因 + "重试失败项"按钮，Remote 同样适用）。

4

配方对比 + 克隆 Diff

中等低频

问题：克隆（Clone）只复制，不告诉你"新配方和原配方差在哪"；两个配方参数对比只能人肉左右滚动比对。

方案：选中两个配方进入对比视图：左右双栏参数表，逐行按 名称/地址/值 对齐，差异行高亮（黄=修改、绿=新增、红=删除），顶部摘要"差异 3 项 / 新增 1 / 删除 2"；克隆入口改为"克隆并对比"，保存前展示待改差异。

5

最近下发历史 + 一键重发 + 收藏置顶

易实现中收益

问题：下发无痕——什么配方、什么时候、下到哪台设备、成功与否全部不可查；换班重复下发同一配方要重新走一遍选择。

方案：页面底部折叠面板"最近下发"（时间 / 配方 / 设备 / 结果 / 耗时），失败可"重试"、成功可"再次下发"；下发记录落盘 recipes 侧 JSON（或独立 audit 表，复用 AuditService）；卡片列表支持收藏 ★ 置顶。

落地建议

阶段方案理由
第 1 批（快赢）① 卡片+搜索筛选 　② DataGrid+校验天天用的入口，消除卡顿与"保存成功但下发失败"的返工，无风险
第 2 批③ 下发向导 　⑤ 下发历史防误下发事故 + 操作留痕，改动集中在页面与 VM
第 3 批④ 对比/克隆 Diff低频但锦上添花，可挂在 ② 的 RowViewModel 之上
