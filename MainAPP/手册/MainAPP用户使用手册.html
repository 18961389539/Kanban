MainAPP 用户使用手册

1. 第一次使用前

MainAPP 用来查看生产、设备状态、报警、历史和工单。第一次启动前，请让设备管理员确认：

  • 电脑已连接到 PLC 所在网络，并知道 PLC IP 地址和端口。
  • 已经准备好设备名称、OK/NG/状态/报警地址。
  • 已经确认班次开始和结束时间。
  • 当前电脑已完成授权或仍在试用期内。

启动程序

  1. 双击 MainAPP.exe 或桌面快捷方式。
  2. 等待主窗口出现。
  3. 如果弹出授权窗口，按授权管理操作。
  4. 首次启动先打开设置，确认 PLC 和班次，再进入设备管理。
程序默认以大屏模式打开。非 16:9 屏幕出现留边是正常现象，目的是避免内容被裁切。

2. 认识主界面

左侧导航栏切换页面，底部显示 PLC 连接状态。鼠标停留在图标上可看到提示。

图标/页面用途
首页快速查看整条生产线核心指标。
产线按产线和设备布局查看现场状态。
报警中心查看活跃报警、触发次数和恢复记录。
设备管理管理设备、PLC 地址、报警和缺陷点。
历史查询查询生产、报警和状态历史。
生产概览查看趋势、产量和 OEE 汇总。
设置修改 PLC、班次、刷新和授权设置。
工单管理创建、分配和跟踪生产工单。
运行监控检查采集服务和电脑资源。

PLC 状态

绿色圆点表示 PLC 已连接；红色圆点表示未连接或连接失败。断线次数是本次运行期间的连接断开次数，不是报警数量。

3. 日常开机操作

启动 MainAPP→检查授权→检查 PLC 连接→检查设备和班次→查看报警→开始监控
  1. 启动程序并等待页面加载。
  2. 确认左下角 PLC 状态为绿色。
  3. 打开运行监控，确认采集服务正在运行。
  4. 打开报警中心，优先处理高等级报警。
  5. 返回首页，确认设备数量和生产指标正常。

4. 首页：看懂生产情况

首页适合快速浏览。重点查看设备状态、当前速度、总产量、不良数、目标节拍和实际节拍。

运行
设备正在生产。
暂停
设备暂时停止，不一定是故障。
报警
存在需要处理的报警。
离线
系统无法获得有效数据。

首页长时间不更新时，依次检查 PLC 连接、运行监控、最近成功采集时间，必要时点击刷新。不要自行删除数据库。

5. 报警中心

处理一条报警

  1. 点击左侧铃铛图标。
  2. 查看实时活跃报警，先处理高等级报警。
  3. 根据报警名称和设备名称到现场确认原因。
  4. 处理现场故障后等待 PLC 信号恢复。
  5. 确认报警从活跃列表消失或变为已恢复。
  6. 需要追溯时，在历史查询中查看发生和恢复时间。
“活跃报警为 0”只表示当前没有活跃报警，不表示今天没有发生过报警。

报警不消失

先确认现场设备、PLC 连接、报警地址和报警点是否启用。不要直接删除报警记录，否则会影响追溯。

6. 设备管理

添加设备前准备

信息示例用途
设备名称注塑机 1页面显示名称。
OK 计数地址D100良品计数器。
NG 计数地址D110不良品计数器。
状态地址D120设备状态或状态计数。
复位地址M100班次切换时使用。
报警地址M200报警 PLC 位地址。

添加步骤

  1. 进入设备管理，点击新增设备。
  2. 填写名称、OK、NG、状态和复位地址。
  3. 在报警、缺陷或计数报警页添加监控项目。
  4. 检查地址格式、空值和重复地址。
  5. 保存，返回设备列表确认设备出现。
  6. 等待一次采集周期，确认状态和数据变化。

删除设备前先备份配置，并确认不再需要继续采集和查询该设备。

7. 历史查询

打开时钟图标，选择生产、报警或状态转换查询。

  1. 选择查询类型。
  2. 设置开始时间和结束时间。
  3. 选择设备和班次；不选设备通常表示全部设备。
  4. 点击查询，检查结果数量和时间范围。
  5. 需要留档时使用导出功能。

查询为空时，先检查时间、设备、班次和历史写入状态，不要立即判断现场没有生产。

8. 工单管理

  1. 点击工单图标并新增工单。
  2. 填写工单号、产品、目标数量、设备和计划时间。
  3. 保存并按现场流程设置工单状态。
  4. 生产过程中用首页和历史查询核对实际产量。
  5. 完成后检查目标数量与实际数量差异。
产品名称和工单名称请使用现场统一命名，避免后续统计分散。

9. 设置

PLC 连接配置

  • IP 地址：PLC 的局域网地址。
  • 端口：由现场通信配置确定，示例常见为 4999。
  • 轮询间隔：读取设备的时间间隔，单位毫秒。
  • 历史写入间隔：每多少次扫描写入历史快照。
  • 主页刷新间隔：首页显示刷新间隔。

修改后检查数值不是 0 或负数，点击保存，等待连接更新，再到运行监控确认采集周期。轮询过快会增加 PLC 和电脑负载。

班次配置

填写班次名称、开始时间和结束时间。跨午夜班次要确认结束时间属于第二天的逻辑范围。班次名称已经用于历史统计后，不建议频繁修改。

10. 授权管理

设置页顶部会显示试用期、已激活或异常状态。

  1. 记录页面显示的机器码。
  2. 将机器码提供给授权管理员。
  3. 获取对应激活码并输入。
  4. 点击激活，确认显示“已激活”。

激活码通常与机器绑定，不要将其他电脑的激活码直接复制使用。

11. 运行监控

运行监控页面用于判断“系统是否健康”，重点看：

项目正常表现异常表现
PLC 连接已连接未连接、反复重连
采集服务正在运行已停止
最近成功设备数大于 0，或确实无设备长时间为 0
最近采集时间持续更新长时间不变
连续失败周期0 或偶尔增加持续增加
系统资源内存和磁盘充足内存高、磁盘接近满

判断系统故障时，至少同时检查 PLC 状态、最近成功采集时间和连续失败周期。

12. 常见问题

PLC 一直未连接

检查网线、交换机、PLC IP、端口和 PLC 是否允许当前电脑连接。

首页产量不增加

确认设备在生产、PLC 已连接、OK/NG 地址正确，并查看最近成功采集设备数。

设备离线但 PLC 绿色

PLC 绿色只代表 PLC 连接正常，不代表每台设备地址正确。检查该设备地址和采集结果。

报警中心没有现场报警

检查报警点是否添加、启用，并确认报警 PLC 地址正确。

历史查询没有数据

检查时间、设备、班次和历史写入状态。刚产生的数据可能尚未到下一次历史写入周期。

程序启动失败

保留完整提示、发生时间、最近修改内容和 %APPDATA%\Kanban 下的日志，联系管理员。不要直接删除配置和数据库。

13. 日常关机与备份

  1. 确认没有正在执行的生产复位或配置保存。
  2. 按现场要求更新工单状态。
  3. 关闭 MainAPP 窗口并等待程序退出。
  4. 需要备份时复制整个 %APPDATA%\Kanban 目录。

新手最重要的三条规则

  1. 先看 PLC 连接，再判断数据是否异常。
  2. 先确认地址表，再修改设备配置或执行写入命令。
  3. 先备份数据目录，再删除设备、修改班次或处理配置损坏。
