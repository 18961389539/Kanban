RESX ↔ CSV 转换工具

多语言资源互转 · 本地运行 · 支持预览与编辑
将 .resx（可多选，自动按 Key 对齐）或 .csv（首列 Key，其余列为语言）拖到这里，或点击加载文件

使用说明

  1. resx → CSV：加载多个 resx（如 Strings.resx / Strings.en.resx / Strings.ja.resx）， 自动按 Key 合并，导出为 Key,Strings,Strings.en,Strings.ja 一列一语言。
  2. CSV → resx：加载 CSV（首行表头：Key,语言名…）， 每个语言列导出为一份 语言名.resx。
  3. 表格中可直接编辑单元格；红底 ⚠ 空值、 ＋ 缺语言 高亮提示；支持搜索、增删行。
  4. 所有处理均在浏览器本地完成，文件不会上传。

CSV 格式

标准 RFC 4180（引号包裹含逗号/换行的值）， 导出带 UTF-8 BOM，Excel 可直接打开中文。

CSV 原文预览
Key 排序保持加载顺序；同一语言重复 Key 取最后一个。生成 RESX 含标准 resheader，兼容 .NET ResXResourceReader。
